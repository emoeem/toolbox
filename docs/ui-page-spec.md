```
┌────────────────────────────────────────────────────────────┐
│  Toolbox                                    [🔍 搜索 Ctrl+K] │

│  最近文件                                                   │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │ 缩略图    │ │          │ │          │ │          │       │
│  │ 名称      │ │          │ │          │ │          │       │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘       │
│                                                            │
│  快速开始        │  工具分类                                │
│  [打开图像…]     │  编辑 · 创作 · 批量 · 分析 · AI · 文件工具 │
│  [拖放图像到这里] │  （ToolCard 网格，含收藏/最近使用）        │
```

- 空状态（无最近文件）：虚线拖放区 + "打开图像"主按钮，不放示例广告位。

- 快捷键：Ctrl+O 打开；Ctrl+K 搜索；Enter 打开选中最近文件。

## 2. EditorPage（图像编辑工作区，核心页）

```
┌──────────────────────────────────────────────────────────────────┐
│ TopToolbar: [打开][保存][另存] │ [↶撤销][↷重做] │ [缩放控件] │ 文件名●│
├────┬────────────────────────────────────────────┬────────────────┤
│Nav │  ┌──────────────────────────────────────┐  │ Inspector      │
│Rail│  │                                      │  │ ┌────────────┐ │
│    │  │        ImageCanvas                   │  │ │页签:调整|滤镜│ │
│ 编辑│  │  (canvasBackdrop 背景 + 棋盘格)      │  │ ├────────────┤ │
│ 创作│  │                                      │  │ │参数控件组   │ │
│ 批量│  │                                      │  │ │(自动生成)   │ │
│ …  │  └──────────────────────────────────────┘  │ │[应用][重置] │ │
│    │  底部浮层: TaskQueuePanel（可收起）          │ └────────────┘ │
├────┴────────────────────────────────────────────┴────────────────┤
│ StatusBar: 1920×1080 · 100% · sRGB · 鼠标 512,384 · 任务摘要      │
└──────────────────────────────────────────────────────────────────┘
```

区域行为：

| 区域 | 行为 |
|---|---|
| ImageCanvas | 滚轮缩放（指针为中心）、拖动平移、双击适配、`1` = 100%、`F` = 适配窗口、`Esc` 取消在途预览；透明像素显示棋盘格 |
| 检查器·调整页签 | 亮度/对比度/饱和度/曝光/色相/自然饱和度/高光/阴影（滑杆 + 数值输入双向绑定）；[应用] 提交全分辨率任务；[重置] 回滚到已应用状态 |
| 检查器·滤镜页签 | 流程 2（分类/搜索/参数/链/预设） |
| TopToolbar | 撤销/重做按钮随 HistoryModel canUndo/canRedo 启停；缩放控件显示数值可输入（numeric 角色）；未保存修改显示 `●` |
| StatusBar | 点击任务摘要展开 TaskQueuePanel |

状态：

- 空态（未打开文档）：画布区显示引导（打开/拖放），检查器与工具栏编辑类按钮禁用。
- 加载态：打开大图时画布显示 ProgressIndicator，先显示低清快速预览。
- 错误态：打开失败 → 空态 + Toast（错误码 + 消息）。
- Worker 不可用：检查器显示降级横幅（warning），画布仍可查看已加载数据。

## 3. BatchPage（批量处理）

```
┌──────────────────────────────────────────────────────────────┐
│ 批量处理                              [导入文件] [导入目录]     │
├──────────────────────────────┬───────────────────────────────┤
│ 文件列表                      │ 配置                          │
│ ☑ img_001.jpg   待处理        │ 操作: [格式转换 ▾|滤镜链 ▾]    │
│ ☑ img_002.png   处理中 45%    │ 输出目录: [____] [浏览]        │
│ ☐ img_003.jpg   失败 E_FORMAT │ 命名: {original}.{ext}        │
│ …                            │ 格式/质量/覆盖策略 …           │
│                              │ [开始] [取消] [重试失败项]      │
├──────────────────────────────┴───────────────────────────────┤
│ 摘要: 成功 12 · 失败 1 · 取消 0      [打开输出目录]            │
└──────────────────────────────────────────────────────────────┘
```

- 文件项状态用色点 + 文本（不用纯颜色区分，保证可访问性）。
- 失败项可展开查看错误详情并可复制。
- 运行中禁止修改配置（控件禁用），允许取消。

## 4. SettingsPage（设置）

分组（总纲 §9.10），左侧分组列表 + 右侧表单：

| 分组 | 内容 | 阶段 |
|---|---|---|
| 外观 | 主题(深/浅/跟随系统)、UI 字体、等宽字体、字号、动画偏好、字体预览、恢复默认、字体诊断 | P0 核心 |
| 工作区 | 面板布局重置、默认工具、最近文件开关 | P0 核心 |
| 性能 | 预览质量、并发任务数、缓存策略 | P0 核心 |
| 后端 | Python Worker 路径/版本/协议版本/启动状态、重启按钮 | P0 核心 |
| 外部依赖 | gmic/ffmpeg/tesseract/upscayl 等实际检测状态与安装指引 | P0 核心 |
| 存储 | 缓存目录与大小、清理按钮、预设目录 | P1 |
| 关于 | 版本、协议版本、许可证、第三方声明 | P0 核心 |

字体设置必须展示三层诊断（总纲 §11.3）：配置值 → Qt 实际解析 → 文本回退覆盖
（复用 `app/fonts.py diagnose()` 的语义，由 Worker `font.diagnose` 动作提供，Phase 3 扩展动作）。

## 5. Studio 页规格要点（P1，布局级）

| 页面 | 布局要点 | 特有状态 |
|---|---|---|
| FractalPage | 左：公式/参数/着色；中：预览画布（缩放/导航）；右：导出与预设 | 渲染进度可取消； Julia 常数联动显隐 |
| TexturePage | 左：生成器/预设列表；中：预览 + 平铺预览切换；右：参数 | 种子可重复；G'MIC 缺失时该生成器置灰 |
| ShaderPage | 左：模板/库列表；中：GLSL 编辑器（等宽/高亮/行号）+ GL 预览；右：uniform 参数 | 编译错误内联显示；验证依赖 glslangValidator 缺失时降级 |
| GradientPage / PhotomosaicPage / FusionPage | 统一"参数在左、预览在中、导出在右"三栏 | Photomosaic 素材数量校验 |

## 6. 通用页面状态（总纲 §7.3-9 的落地）

每个页面必须显式处理：空态 / 加载态 / 错误态 / 无后端态 / 禁用依赖态。
统一实现于布局组件层（WorkspaceLayout 提供 `emptyText`、`loading`、`error`、
`backendDown` 插槽），页面不得自行发明样式。
